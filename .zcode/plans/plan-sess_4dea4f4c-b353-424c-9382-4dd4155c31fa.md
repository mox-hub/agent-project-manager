# SubPageToolbar 二级子页面工具栏：抽取组件 + 10 处页面改造

## 已确认决策
- shell 级项目上下文栏统一替换为新组件（顺带修复 `roles` 子页不显示上下文栏的存量 bug）
- 侧栏按钮按页面注入：有右侧面板的页面显示并控制，无面板不渲染
- member/team 详情页顺带接入路由（含 tabs-registry 注册）并迁移

## 1. 新组件 `components/ui/sub-page-toolbar.tsx`

布局与 ToolbarRow 一致：`grid-cols-[minmax(0,1fr)_auto_minmax(0,1fr)]`、`px-6 py-2 md:px-7`、单行、无上下分界线。

```tsx
interface SubPageToolbarProps {
  aiId?: string; className?: string;
  onBack?: () => void;              // ① 最左返回按钮，默认 navigate(-1)（HeaderActionButton ghost + ArrowLeft）
  backLabel?: string;               // 默认 "Back"
  breadcrumbs?: { label: ReactNode; to?: string }[];  // ② ChevronRight 分隔，可点项为 Link，末项 foreground + truncate
  tabs?: {                          // ③ 居中子页签：SegmentedControl variant="rect"（与主工具栏同款滑块）
    value: string;
    onChange: (value: string) => void;
    items: { value: string; label: string; icon?: LucideIcon; to?: string }[];
  };
  pager?: {                         // ⑤ 翻页器：按钮组左侧，两个 ghost 圆按钮 + tabular-nums 计数
    hasPrev: boolean; hasNext: boolean;
    onPrev: () => void; onNext: () => void;
    position?: ReactNode;           // 如 "3/12"，缺省 "—"
  };
  actions?: ReactNode;              // ④ 自定义按钮组（HeaderActionButton 实例/Badge 等）
  sidebar?: { open: boolean; onToggle: () => void };  // ④ 最后一个固定按钮（outline，PanelRight/PanelRightClose），不传不渲染
}
```

复用现有资产：HeaderActionButton、SegmentedControl(rect)、useEntityNavigation（task/bug 翻页数据）、ProjectSidebarContext（项目子页侧栏开关）。

3. **bug-detail-page**：同上（Bugs 面包屑 + bug 翻页 + aside 控制）
4. **acceptance-detail-page**：顶部导航条 → SubPageToolbar（返回→/app/acceptance；面包屑 [验收中心, 标题]；actions = Approve(primary)/Reject(danger)）
