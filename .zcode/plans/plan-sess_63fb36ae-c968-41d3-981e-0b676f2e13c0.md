## 二、后端：新增 MCP 接入 + Skills（参照 cli-provider 模块范式）

**1. mcp-registry（外部 MCP server 管理）**——扩展 apps/server/src/modules/mcp-server/：
- prisma 新表 `McpServerConfig`（migration `add_mcp_server_config`）：id、name(unique)、transport('stdio'|'http'|'sse')、command/args(Json)/env(Json)（stdio）、url/headers(Json)（http/sse）、enabled、lastStatus/lastError/toolCount/lastPingAt（探活缓存）、metadata(Json)、timestamps——结构对齐 CliProviderConfig 惯例
- 连接层 `McpClientRegistry`：用已安装的 `@modelcontextprotocol/sdk@1.27.1` 的 `Client` + `StdioClientTransport`（本地命令，Windows 下经 shell 包装 npx）/ `StreamableHTTPClientTransport`（远程，sse 场景回退 SDK 的 SSEClientTransport），带 5s 超时；`connect()` → `listTools()` → 写回 toolCount/status/lastPingAt，失败写 lastError
- endpoints（JwtAuthGuard + Swagger，前缀 /_api）：`GET /mcp/servers`（配置+缓存状态合并返回）、`POST /mcp/servers`、`PUT /mcp/servers/:id`、`DELETE /mcp/servers/:id`、`POST /mcp/servers/:id/refresh`（单卡探活）、`POST /mcp/servers/refresh-all`；沿用 MessageBus 事件（mcp.server.updated 等）
- 保留现有 /mcp/status 与 SSE 对外服务不动

**2. skills 模块**（新 apps/server/src/modules/skills/，轻量）：
- prisma 新表 `SkillConfig`（migration `add_skill_config`）：key(unique)、name、description、category、source('builtin'|'custom')、enabled、metadata、timestamps；seed 写入前端 mock 对齐的 7 个内置技能（code-review / bug-analysis / test-gen / doc-gen / refactor / pm-assist / planning）
- endpoints：`GET /skills`、`PUT /skills/:key`（启用禁用/更新）；后续可扩展 Anthropic Agent Skills（SKILL.md 目录）扫描作为 custom 来源，本轮不做

**3. 技术选型说明**：SDK 维持已安装的 1.27.1（与现有 Server 端用法同版本线；v2 属 2026-07-28 新 spec，现有 SSE server 代码也未迁移，一并升级风险大，不混线）。
