### 1.4 与宪法 §15 逐条对照（证据清单）

#### §15.1「断点沿用 Tailwind 默认，禁自定义」——**基本合规，1 类存疑**

- `@theme --breakpoint-*` 自定义断点：**0 处** ✅
- 裸 `2xl:` / `3xl:` 断点：**0 处** ✅（注意：全仓 70 处 `2xl` 字面量全部是 `text-2xl` / `max-w-2xl` / `blur-2xl` / `shadow-2xl`，**不是断点**，用词边界可区分）
- ⚠️ **存疑 1 类：2 处任意值容器查询**，`src/modules/auth/components/auth-shell.tsx`：

```
33: 'flex w-full flex-col px-6 py-6 @min-[920px]:w-104 @min-[920px]:shrink-0 @min-[920px]:px-10',
47: <div className="hidden flex-1 p-4 pl-0 @min-[920px]:block">
```

`@min-[920px]:` 是 Tailwind v4 的**容器查询**（按父容器宽度而非视口），断点值 920px 不在 §15.1 的五档里。**这是「自定义断点」的实质**，但形式上是容器查询而非媒体查询，§15.1 的条文没有覆盖它 → **需人裁决**（见 §4 存疑清单 S-1）。

#### §15.2「最低支持宽度 1024px / lg 基准态」——**无从静态验证，但发现 1 处风险**

§15.2 要求「`lg` 以下不承诺移动端可用性」。这与 §15.4「lg 以下不得隐藏关键操作」并用时，**必须确认** `lg` 以下是否有操作彻底消失。见下条。

#### §15.4「禁止在 `lg` 以下隐藏关键操作」——**发现 1 处真违规 + 13 处可接受**
