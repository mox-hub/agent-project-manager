### 2.2 存量兼容（localStorage）

- key 保持 `theme-preset`（不改 key，避免双重迁移）
- 存量值可能是 `"linear"`（旧装）或 `"figma"`/`"notion"`（更早）
- 策略：`getInitialThemePreset()` 白名单只认 `"default"`，**其余一切值（含 `"linear"`）回落 `"default"`**，并在读取时顺手覆写回 `"default"`（自愈）

```ts
export function getInitialThemePreset(): ThemePreset {
  if (typeof window === "undefined") return "default";
  const stored = localStorage.getItem(STORAGE_KEY);
  if (stored === "default") return stored;
  // 历史存量（figma / notion / linear）与未知值一律回落 default 并自愈
  if (stored !== null) localStorage.setItem(STORAGE_KEY, "default");
  return "default";
}
```

**实测补强**：`setPreset` 在仓库中**无任何消费方**（`theme-context.tsx:124` 定义、`:133` 挂载，全仓无调用）——即 `persistThemePreset` 实际从未被触发，localStorage 里大概率根本没有该 key。上述兼容是**防御性**的，不是必需的。这同时说明 preset 是**死接口**。

**死接口裁决（待确认，见 §七-T4）**：
- 建议 **A（推荐）**：保留 `ThemePreset` 类型 + context 字段（宪法 §5.6 明确要求「保留 preset 接口」），但加注释说明「当前无 UI 入口，接口为未来多主题预留」；同时把 `setPreset` 从 context 值中**移除**（无消费方的公开 API 是负债），需要时再加回。
- 建议 B：原样保留，只加注释。

## 三、Tailwind theme 强制语义转换

### 3.1 现状盘点：哪些是「数字直读命名」

| 命名空间 | 数字直读项 | 语义项（保留） | 完全缺失项 |
|---|---|---|---|
| `--text-*` | **9 个**：`8/9/10/11/13/15/22/28/32` | 无（`xs`/`sm`/… 走 Tailwind 默认） | — |
| `--radius-*` | **5 个**：`3/5/8/10/14` | `xs`/`sm`/`md`/`lg`/`xl`/`chip` | — |
| `--spacing-*` | **42 个**显式固化档 + 6 个冻结四分之一档 | `dialog`/`dialog-wide`/`dialog-screen`/`dialog-scroll`/`dialog-full` | — |
| `--color-chart-*` | **5 个**：`1..5` | — | — |
| `--shadow-*` | — | — | **完全缺失（0 个 token）** |
| `--duration-*` / `--ease-*` | — | — | **完全缺失**（`--motion-*` 定义在 `:root`，未注册进 `@theme`） |
| `--leading-*` / `--font-weight-*` | — | — | 未声明，走 Tailwind 默认 |
| `--z-*` | — | — | **完全缺失** |

> **关键澄清（决定方案边界）**：Tailwind v4 的「theme」= 默认 theme + 本仓 `@theme` 增量。
> `text-sm` / `leading-relaxed` / `font-medium` / `z-50` **本身就是 theme 取值**（Tailwind 默认 theme），
> 不是「自定义」。因此「强制语义转换」的**靶子只有一类：以数值命名的 token**（上表第 1-4 行），
> 加上「本仓该有却没有」的类别（第 5-8 行）。**不要求**把 `p-4` / `z-50` 改名为 `p-md` / `z-overlay`。

### 3.2 目标 `@theme` 形态

```css
@theme {
  /* ── 集成品牌色：不变（Linear/Atlassian 官方色） ── */
  --color-brand-linear: #5e6ad2;   /* 等 7 项，保持原样 */

  /* ── 字阶：8 档，全部语义命名（关闭默认命名空间，见 §4.2） ── */
  --text-3xs: 10px;   --text-3xs--line-height: 1.4;   /* 徽标内数字/图表轴/微元数据（非中文） */
  --text-2xs: 11px;   --text-2xs--line-height: 1.45;  /* badge/辅助标签/密集元数据 */
  --text-xs:  12px;   --text-xs--line-height:  1.5;   /* UI 小字基准；中文下限 */
  --text-sm:  14px;   --text-sm--line-height:  1.5;   /* 全站基准 */
  --text-base:16px;   --text-base--line-height:1.6;   /* 阅读型正文 */
  --text-lg:  18px;   --text-lg--line-height:  1.5;   /* 卡片/面板标题 */
  --text-xl:  20px;   --text-xl--line-height:  1.4;   /* 区块大标题 */
  --text-2xl: 24px;   --text-2xl--line-height: 1.3;   /* 页面标题 */

  /* ── 圆角：语义分档（关闭数值档） ── */
  /* --radius-xs/sm/md/lg/xl/chip 沿用 index.css:93-97 的 @theme inline 桥接，不动 */

  /* ── 阴影：全站唯一档（关闭默认命名空间） ── */
  --shadow-xs: 0 1px 2px 0 rgb(0 0 0 / 0.05);

  /* ── 动效：白名单可写（关闭默认命名空间） ── */
  --duration-fast:   120ms;   /* hover/按压微交互 */
  --duration-normal: 180ms;   /* 展开/弹出/常规过渡 */
  --duration-slow:   240ms;   /* 大面积面板、强调 */
  --ease-standard: cubic-bezier(0.2, 0, 0, 1);
  --ease-emphasis: cubic-bezier(0.16, 1, 0.3, 1);

  /* ── 间距：语义档（数值档不再显式声明） ── */
  --spacing-cell-y:  0.375rem;  /* 单元格 py-1.5 */
  --spacing-gutter:  1rem;      /* 卡片/表单字段间 16px */
  --spacing-section: 1.5rem;    /* 区块垂直间距 24px */
  --spacing-page:    1.5rem;    /* 页面水平边距 24px（px-6 档） */
  /* --spacing-dialog* 5 项保留 */

  /* ── 其余（--color-* 语义桥接、--animate-*、border-1.5 等）不变 ── */
}
```

**删除**：`--text-8/9/13/15/22/28/32`（7 项）、`--radius-3/5/8/10/14`（5 项）、42 个数值 `--spacing-*`（含 6 个冻结档）。

### 3.3 字阶硬切：`text-10` → `text-3xs`，`text-11` → `text-2xs`

**实测规模**：

| 旧名 | 新名 | 命中数 | 涉及文件 |
|---|---|---|---|

## 四、宪法新增「页面只能从 theme 取值」条款 + lint 强化

### 4.1 新增宪法条款（建议放在 §4 之前，作为独立的 §4「取值合法性」或并入 §5 前）

```markdown
## §N 取值合法性（唯一取值原则）[MUST]

N.1 **页面的每一个视觉属性（颜色、字号、间距、圆角、阴影、行高、字重、动效时长/缓动、层级）
     只能取自 `src/index.css` 的 `@theme`。**禁止自定义值，具体包括：
   (a) 任意值语法 `w-[260px]`、`text-[13px]`（`lint:tokens` 拦）；
   (b) 原生色板类 `bg-blue-500`、无编号裸色 `bg-white`/`text-black`（`lint:palette` 拦）；
   (c) 内联颜色字面量 `style={{ color: '#8B5CF6' }}`（`lint:palette` 拦）；
   (d) 以数值命名的刻度 token（`text-10`、`rounded-14` 等，`lint:spacing` 拦）；
   (e) 未在本仓 `@theme` 中登记的刻度命名空间成员（`text-3xl`、`shadow-md`、`duration-300`
       等——见 N.2）。

N.2 **命名空间封闭**：本仓对以下命名空间执行 `--<ns>-*: initial` 重置，只保留宪法登记的档位：
     `--text-*`、`--radius-*`、`--shadow-*`、`--duration-*`、`--ease-*`。
     被重置的命名空间中，未登记的类**不生成任何 CSS**——这是刻意的：写错即失效，不允许「写了但没生效」。

N.3 **间距例外**：`--spacing-*` 不重置。Tailwind 的 4px 网格倍数键（`p-4`、`gap-3`、`w-65`）
     是主题派生值（`calc(var(--spacing) * N)`），**视为合法 theme 取值**；
     但四分之一档（`.25`/`.75` 结尾）冻结禁新增（§4.1）。

N.4 **语义优先**：同一视觉意图必须用语义 token 表达（`--color-accent-blue`、`--shadow-xs`、
     `--spacing-section`），禁止「用相邻档位凑」；凑档即视为自定义值。

N.5 违反 N.1 的存量必须在附录 A《豁免清单》登记（文件 + 原因 + 清除批次），
     登记不等于许可，须给出清除时间。
```

### 4.2 机制：命名空间封闭（本方案的技术基石）

Tailwind v4 支持 `--<namespace>-*: initial` 清空命名空间。本仓启用后：

```css
@theme {
  --text-*: initial;      --text-3xs: 10px;  /* …8 档 */
  --radius-*: initial;    /* …沿 @theme inline 桥接 */
  --shadow-*: initial;    --shadow-xs: 0 1px 2px 0 rgb(0 0 0 / 0.05);
  --duration-*: initial;  --duration-fast: 120ms;  /* …3 档 */
  --ease-*: initial;      --ease-standard: …;      /* …2 档 */
}
```

**为什么是「封闭」而不是「只靠 lint」**：
- lint 是**检测器**，会有漏网（`check-spacing-governance.mjs` 现在就漏 `3xl-6xl` / `text-12` / `z-*` / `leading-5`）
- 封闭是**物理约束**：`shadow-md` 写下去生成 0 CSS，肉眼可见异常，评审即发现

**⚠️ 封闭的三个已知风险（实施时必须逐一验证）**：

| 风险 | 说明 | 缓解 |
|---|---|---|
| **行高配对丢失** | `--text-*: initial` 会一并清掉 Tailwind 默认的 `--text-base--line-height` 等配对值 → 只声明字号会导致行高回退 | 8 档**必须同时声明 `--text-<n>--line-height`**（见 §3.2 表） |
| **`shadow-none` 失效** | 若 `shadow-none` 也走命名空间 | 声明 `--shadow-none: 0 0 #0000` |
| **动画类连带** | `--animate-*` / `@keyframes` 不受影响，但 `animate-spin` 等默认动画需确认 | 实机跑 `pnpm build` 后比对 `dist` 产物 |

**执行纪律**：封闭**不得与大批量迁移同 PR**。顺序必须是
「先迁移存量 → 验证构建产物 → 再封闭」，否则一次性红灯无法归因。

### 4.3 lint 改造清单（逐脚本）
