# 移动端交互模式——桌面原语映射表

**判据（本表必须自洽）**：每条桌面原语都必须给出**确定的替代模式**，**禁止出现「待定」「视情况」**。给不出替代模式的，一律进 §四「不迁移清单」（＝明确回桌面）。

**一句话前提**：桌面原语大量存在的原因是**指针（hover/右键/精确命中）+ 大画布（多栏/表格）+ 物理键盘（命令面板/快捷键）**三件套。触摸屏上这三件套全部不存在，替代模式必须围绕**单指、44pt 命中区、单列、无悬浮态**重建设计。

## 一、桌面原语 → 移动替代（必答表）

| # | 桌面原语 | 实现落点（前端） | 为何无对应物 | 移动替代模式 | 影响的能力卡 |
|---|---------|-----------------|-------------|-------------|-------------|
| P1 | **hover 悬浮预览**（行悬停出浮卡） | `itemPreviewPath` + `floating-layers` 命中判定 | 触摸无 hover 态；hover 事件在触屏上要么不存在要么被 tap 吞掉 | **长按 400ms → 预览 Bottom Sheet**（松手不导航）；短按直接进详情页 | M-02/M-04/M-06 |
| P2 | **右键菜单**（`onContextMenu` 事件期构建） | 右键构建菜单（PRINCIPLES §21 渲染期开销律） | 无右键；手势被系统占用 | **行左滑出 swipe actions（≤3 个主行动作）+ 行尾 `…` 进 ActionSheet**（全量动作）；长按不承载菜单（已给 P1 预览） | M-02/M-04/M-05/M-06 |
| P3 | **底部 Dock 栏**（可自定义/自动隐藏/常驻开关） | `shared/components/bottom-dock` | 桌面 chrome；移动端底部空间已被系统手势条占据 | **Bottom Tab Bar（4 项固定，不自定义）**：`收件箱 / 执行 / 工单 / 我的`；「发起」由 FAB 承担（见 P4） | M-02/M-06/M-07 |
| P4 | **全局命令面板**（⌘K / `mod+shift+f` 全局搜索） | `CommandPalette`（命令 + 搜索双模） | 无物理键盘心智；竖屏全屏面板与系统搜索/键盘争抢 | **顶部搜索入口**（收件箱/工单页头放大镜 → 搜索页，只搜实体 `GET /search`，无命令面）+ **FAB → 快捷创建**（发起需求 / 新建评论）。快捷键体系（CAP-A-17）**整体不迁移** | M-06/M-07 |

| P6 | **表格 / 高密度 DataList** | `DataTable` / `TaskTableView` / 六页表格视图 | 多列超窄屏无法阅读；行内交互（hover 操作列）失效 | **卡片列表（2–3 关键字段）+ 详情页分区**；排序/筛选/视图档位收进**顶部筛选抽屉**；**不提供表格视图**（视图形态完整性的「表格档」是桌面专属） | M-04/M-05/M-06 |
| P7 | **窗口二态制**（紧凑窗口/完整窗口） | `useDesktopCompactWindow`、窗口二态制（PRINCIPLES §20.9） | 移动端单窗 + 前后台生命周期，无窗口尺寸概念 | **状态持久化 + 恢复上次路由**；**后台暂停轮询、回前台重连并补拉**；不做窗口态 | M-08 |

| P9 | **视图形态切换**（list / table / grid / board 四档 + 快照持久化） | `ToolbarRow` + 视图快照 | 四档中 table/board 在窄屏不可用 | **收敛为单一卡片列表形态**；视图档位偏好不迁移 | M-04/M-05/M-06 |

| P11 | **Ctrl/Cmd 长按 → 可解释卡**（AISlot） | `ai-slot-layer`（Ctrl+左键 500ms） | 无修饰键 | **长按 500ms → 长按菜单**（解释 / 复制链接 / 指派）；长按语义与 P1 预览**按对象类型二分**（卡片对象→长按菜单，列表行→长按预览），不叠加 | M-06 |
| P12 | **文档富文本深编辑**（CodeMirror 6 / MDX） | CodeMirror + MDX 管线 | 编辑器是键盘密集型；移动键盘与光标操控体验断崖 | **只读渲染 + 追加评论**；不迁移编辑（进 §四） | — |
| P13 | **Dialog 套件（宽度五档）** | `ui/dialog`（sm~full） | 宽度档在单列屏无意义 | **全屏 Modal**（表单/确认）或 **Bottom Sheet**（轻量确认）；二者二选一，**不设宽度档** | 全体 |
| P14 | **Toast / 通知气泡** | toast 宿主 | 有对应物 | 原生 **Snackbar**（底部，避开 Tab Bar）；权限类用系统 Alert | 全体 |
| P15 | **无限滚动 / 分页** | 列表分页 + PAGE_SIZE | 有对应物 | **下拉刷新（pull-to-refresh）+ 触底加载更多**；不做「滚动全量」（§21 数据窗口律在移动端表现为**必须分页**） | 全体 |

## 二、交互冲突与裁决（写入 `PRINCIPLES-MOBILE.md` §8）

| # | 冲突 | 裁决 |
|---|------|------|
| C1 | iOS **左缘返回手势** vs 行内 **swipe actions** | **列表区 swipe 只在距左缘 ≥ 24pt 起生效**；左缘 24pt 归系统返回。Android 无边缘返回冲突，但硬件返回键优先于行内手势 |
| C2 | iOS **左缘返回** vs **Bottom Sheet 下滑关闭** | Sheet 为**全屏**时左缘手势交系统（返回 = 关 Sheet）；Sheet 为**半屏**时下滑关闭生效、左缘手势仍交系统 |
| C3 | **长按预览**（P1） vs **长按菜单**（P11） | 按对象**类型**二分，**同一对象只给一种**：列表行→长按预览；卡片/实体对象→长按菜单。禁止长按后再长按分层 |
| C4 | **下拉刷新** vs **列表滚动** vs **横向 swipe** | 竖直手势（刷新/滚动）与水平手势（swipe）**正交**：行内 swipe 阈值 ≥ 48pt 水平位移才触发，滚动中不触发 |
| C5 | **Android 硬件返回键** vs 应用内导航栈 | 硬件返回 = **栈 pop**；栈底再返回 = **确认退出**（不静默退出）；Modal/Sheet 打开时，返回 = 关闭 Modal 而非 pop 页面 |
| C6 | **系统字体放大（Dynamic Type）** vs 固定高度容器 | 所有容器**高度自适应**，禁止固定高度承载文本；Tab Bar / 工具栏高度随系统字号上限保护（见 `PRINCIPLES-MOBILE.md` §4/§10） |

## 四、不迁移清单（明确非目标，一律回桌面）

> 本节是「产品定位＝伴随式掌上治理台」的**负向定义**，与能力卡边界声明一致。任何把下列内容搬上移动端的提案**必须先修正本表**（走 requirement-intake）。

| # | 不迁移项 | 原因 |
|---|---------|------|
| X1 | 代码编辑 / 文档富文本编辑 / MDX（P12） | 键盘密集型，移动体验断崖 |
| X2 | 流程画布 / 看板拖拽（P10） | 高密度拖拽容器，与系统手势冲突 |
| X3 | 工作区管理（创建/初始化/仓库绑定/备份恢复） | 运维级操作，出错代价高，需完整上下文 |
| X4 | 表格视图与多列高密度清单（P6 的表格档） | 窄屏不可读 |
| X5 | 命令面板与快捷键体系（P4 的快捷键部分） | 无物理键盘心智 |
| X6 | 全局搜索的完整命令面（可保留「搜实体」子集） | 与系统搜索/键盘争抢 |
| X7 | 设计系统展示页 / 管理页 / 插件与集成配置 | 配置面，低频且字段密集 |
| X8 | 深度访谈 / grill 澄清全流程（CAP-P-01） | 多轮长会话，回桌面 |
